# Gold Calculator Flutter MVP v0.2

نسخه MVP رابط کاربری فارسی/RTL برای ماشین حساب تخصصی طلافروش ایرانی.

## قابلیت‌های این نسخه
- طراحی RTL و responsive
- استفاده کاملاً آفلاین برای محاسبات
- قیمت‌ها به صورت دستی وارد می‌شوند؛ هیچ API قیمت لحظه‌ای لازم نیست
- حالت فروش طلا
- حالت خرید از مشتری
- حالت تعویض
- حالت آبشده
- محاسبه معکوس فروش بر اساس بودجه
- تبدیل عیار
- تاریخچه ۵۰ محاسبه اخیر در حافظه اجرای برنامه
- تنظیمات اولیه مغازه
- گیت اشتراک با وضعیت نمایشی
- موتور محاسبات مستقل در `packages/gold_calculator_engine`
- بدون سرویس پولی و بدون dependency خارجی برای MVP

## اجرای پروژه

نیازمند Flutter SDK است:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

این محیط فعلاً Flutter SDK ندارد؛ بنابراین اجرای واقعی build/run در همین محیط انجام نشده است.
